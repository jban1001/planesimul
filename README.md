# Cabin Focus

비행기 창가에 앉아 멍때리거나 공부하기 위한 웹앱.

여행지를 고르면 인천에서 그곳까지, **활주 → 이륙 → 상승 → 구름 통과 → 순항 → 하강 → 착륙**이 끊김 없이 이어진다. 영상을 이어붙인 게 아니라 창밖 풍경 전체를 실시간으로 그린다.

**→ https://jban1001.github.io/planesimul/**

## 여는 법

브라우저 주소창에 위 주소를 넣으면 끝이다. 설치도, 로그인도, 서버도 필요 없다.

앱처럼 쓰고 싶으면:

- **안드로이드 / 아이폰** — 링크를 열고 브라우저 메뉴에서 `홈 화면에 추가`
- **Windows / Mac** — Chrome이나 Edge 주소창 오른쪽의 설치 아이콘, 또는 앱 안의 `INSTALL` 버튼

한 번 설치하면 아이콘으로 바로 열리고, 주소창 없이 전체 화면으로 뜬다.

## 쓰는 법

| | |
|---|---|
| 왼쪽 위 드롭다운 | 여행지 선택. 기본 20곳 |
| `직접 입력` | 전 세계 아무 도시나 검색해서 그곳으로 비행 |
| `WINDOW` / `FLIGHT MAP` | 창밖 화면과 실제 지도 기반 비행 지도 전환 |
| `FOCUS SESSION` | 25 / 50 / 90분 집중 타이머 |
| `SOUND` | 기내 소음 (화이트노이즈 + 엔진 험) |
| `HIDE UI` | 화면 정리. 되돌리려면 `Esc` |
| `RESTART` | 여정을 처음부터 다시 |

키보드: `M` 화면 전환 · `F` 전체 화면 · `Space` 타이머 · `Esc` UI 복귀

여행지를 바꾸면 즉시 인천 0%에서 새 여정이 시작된다. 지도의 비행기 위치·도착 예정 시각·게이지·고도·속도가 모두 같은 시계를 읽는다.

**여정은 실제 비행 시간만큼 걸린다.** 도쿄는 2시간 10분, 두바이는 8시간 52분, 파리는 11시간 33분. 공부하는 동안 계속 틀어두는 용도라 그렇게 만들었다. 택시 11분, 이륙 활주 40초, 상승 38분, 강하 34분은 노선 길이와 무관하게 고정이고 순항이 나머지를 채운다.

## 창밖은 어떻게 그려지나

프래그먼트 셰이더 한 장이 하늘·지형·공항·구름·날개를 전부 그린다. 클립을 이어붙이지 않으니 **장면 전환이라는 개념 자체가 없고**, 같은 장면이 반복되지도, 전환 중에 검은 화면이 끼지도 않는다.

- **구름** — 적운층을 볼류메트릭 레이마칭으로 통과시킨다. 3D 노이즈 3옥타브로 침식해서 실루엣이 모든 축에서 흐트러진다. 지면에는 같은 구름 필드로 그림자가 진다.
- **지형** — 대륙·구릉·밭·숲·강·마을을 절차적으로 만들고, 높이장에서 유도한 법선으로 태양 음영을 준다. 출발지에서 목적지 지형으로 순항 중에 서서히 넘어간다. 인천을 초록 해안으로 떠나 두바이에 모래로 닿는다.
- **공항** — 실제 활주로 데이터로 그린다. 인천은 16L/34R, 방위 145°, 4000×60m. 중심선·임계표시·조준점·착지대 마킹, 유도로, 계류장, 주기장, 탑승교, 터미널, 활주로등·임계등·진입등.
- **태양** — 날짜와 위경도로 실제 고도와 방위각을 계산한 뒤 기수 방위 좌표계로 회전시킨다. 저녁에 서쪽으로 이륙하면 태양이 실제로 맞는 창에 온다. 목적지가 밤이면 도착도 밤이다.
- **지구 곡률** — 고도에 따라 수평선이 내려간다. 순항 고도가 순항처럼 보이는 이유.
- **후처리** — half-float 프레임버퍼에 선형 HDR로 그린 뒤 블룸을 거쳐 ACES 톤매핑.

프레임 시간을 관찰해서 내부 렌더 해상도(0.42~1.0배)와 구름 레이마칭 스텝(14~34)을 자동으로 조절한다. WebGL을 못 쓰는 환경에서는 실사 영상 폴백으로 넘어간다.

## 로컬에서 실행

정적 파일이라 아무 웹서버나 된다.

```bash
python -m http.server 4173 --directory dist
```

`http://localhost:4173` 을 연다. `file://` 로 직접 열면 서비스워커가 등록되지 않으니 서버를 쓰는 게 좋다.

## 배포

`main` 에 소스가, `gh-pages` 에 `dist` 내용만 루트로 올라간다.

```bash
git push origin main && git subtree push --prefix dist origin gh-pages
```

정적 파일을 고쳤으면 `dist/sw.js` 의 캐시 이름과 `dist/index.html` 의 `?v=` 쿼리를 함께 올린다. 셋이 어긋나면 오래된 캐시가 남는다.

서비스워커가 캐시 우선이라 **업데이트 후 첫 접속은 이전 버전이 뜨고 한 번 더 새로고침해야 최신이 된다.** 버전이 섞이지는 않으니 깨지지는 않는다.

## 파일

```
dist/
  index.html          화면 구조
  style.css           레이아웃과 테마
  app.js              여정 시계, 지도, 타이머, 소리, 여행지
  skyview.js          창밖 렌더러 (WebGL 셰이더 + 블룸 파이프라인)
  journey.js          비행 프로파일, 목적지 바이옴, 태양, 기수 방위
  airports.js         실제 활주로 형상
  sw.js               오프라인 캐시
HANDOFF.md            구현 상세, 좌표계, 함정, 남은 작업
```

## 브라우저

WebGL 되는 최신 브라우저면 된다. Chrome, Edge, Safari, Firefox 모두 확인했다. 구름이 무거우면 해상도가 알아서 내려가고, WebGL 자체가 없으면 영상 폴백으로 동작한다.

## 데이터와 크레딧

- 활주로 형상 — [OurAirports](https://ourairports.com/data/), 퍼블릭 도메인
- 지도 타일 — [OpenFreeMap](https://openfreemap.org/), [OpenMapTiles](https://openmaptiles.org/), 데이터는 [OpenStreetMap](https://www.openstreetmap.org/copyright) 기여자 (ODbL)
- 지도 렌더러 — [MapLibre GL](https://maplibre.org/)
- 위치 검색 — [Open-Meteo Geocoding](https://open-meteo.com/)
- 폴백 영상 — [Pexels](https://www.pexels.com/)

창밖 풍경은 전부 코드로 그린 것이라 사진이나 영상 라이선스가 걸려 있지 않다.
